# 员工端（五合一）

接入用的壳是 `挚邮员工端.html`，由 `原型/10_员工端.html` 复制并改名。原型那一份仍由 `build_10.py` 生成。

旁边的 `hall-wire.js` 把语音、附件、跨岗转交、登录会话交到后端 `/api`。对方岗位登录后能看到待收的转交。导引页上的「写文件」只抄已经知道的字段，没有字段就停住，不自动提交。「调用第三方 IO」停在人，等柜员给出读数。名册、今日数字、`can()`、新建会话的四态判断留在壳上，没有改。

系统页的模型与设定、知识库、数据库管理做在这一份壳的「系统」组里，点开就停在主区域，不跳到 `二级页/08_系统.html`。以后新页面也写进这一份五合一，不再另开页面。数据库口令在「数据库管理」里填写，不写进页面源码。

从 `intelligent-postal-hall/backend` 启动：

```
D:\AIenvironment\python.exe -c "import uvicorn; from app.main import create_app; uvicorn.run(create_app(), port=8008)"
```

浏览器打开 `http://127.0.0.1:8008/挚邮员工端.html`。同一岗位的二级页由服务挂出 `原型/二级页`。跨岗不打开对方的页，只提交转交。
